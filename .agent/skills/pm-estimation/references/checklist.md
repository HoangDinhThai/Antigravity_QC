# Quick Estimation Checklist

## Before Estimation

### Gather Input
- [ ] PRD/BRD document complete?
- [ ] Figma/Wireframes available?
- [ ] Any meeting notes to refer to?

### Confirm Scope
- [ ] Project scope? (MVP / Full / Phase)
- [ ] Required tech stack?
- [ ] Expected timeline?
- [ ] Quality level? (POC / MVP / Production)

---

## During Estimation

### Feature Discovery
- [ ] List all features from PRD
- [ ] Count screens from Figma
- [ ] Identify hidden features:
  - [ ] Authentication
  - [ ] Error handling
  - [ ] Notifications
  - [ ] Admin features
  - [ ] Search
  - [ ] Responsive

### Sizing
- [ ] Size each feature (XS/S/M/L/XL)
- [ ] Apply complexity factors
- [ ] Calculate effort by role (BE/FE/QC)

### Buffer & Risk
- [ ] Add buffer (20-30%)
- [ ] List risks
- [ ] Define assumptions

---

## After Estimation

### Review
- [ ] Compare with similar projects
- [ ] Review with Tech Lead
- [ ] Review with team

### Documentation
- [ ] Clear assumptions?
- [ ] Complete out of scope?
- [ ] Conditions/Validity period?

### Final Check
- [ ] Total effort reasonable?
- [ ] Timeline feasible?
- [ ] Resource allocation OK?

---

## Red Flags ⚠️

Stop and clarify if:
- [ ] No design/wireframe
- [ ] Conflicting requirements
- [ ] Unrealistic timeline
- [ ] Budget fixed before estimation
- [ ] "Like app X but better"
- [ ] "Simple feature" but lacking details

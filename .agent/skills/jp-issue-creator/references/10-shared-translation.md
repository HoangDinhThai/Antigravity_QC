# Shared Translation Rules

## Japanese To Vietnamese Principles

1. Accuracy over literal wording.
2. Keep business meaning and constraints.
3. Use developer-friendly Vietnamese.
4. Keep common technical terms in English where clearer.

## Request Classification Keywords

- Bug: バグ, 不具合, エラー, 障害, 問題
- New Feature: 新機能, 追加, 要望, 改善
- Change: 変更, 修正, 更新
- Priority: 緊急, 急ぎ, 至急, 高, 中, 低
- Reproduction: 再現手順, 操作手順
- Expected: 期待動作, 正しい動作, あるべき
- Actual: 実際の動作, 現状

For extended vocabulary, read `references/jp-vi-dictionary.md`.
